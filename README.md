# BALI Booking

Полноценная система учёта бронирований ночного клуба BALI.

Репозиторий создан как единая кодовая база для:
- Admin Web / PWA;
- Android;
- iOS Web Clip (`.mobileconfig`);
- Windows;
- Google Apps Script API;
- Google Sheets как операционной базы данных.

> Статус: идёт полная пересборка архитектуры и интерфейса администраторской версии.
