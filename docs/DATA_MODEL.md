# Данные

- `EVENTS` — ночные смены и дополнительные мероприятия.
- `BOOKINGS` — брони; `CLIENT_ID`, точное `ARRIVAL_AT`, `CHECKIN_AT`.
- `LAYOUTS` — шаблоны рассадки и координаты столов.
- `EVENT_TABLES` — материализованный список столов конкретного мероприятия; пересобирается при смене схемы.
- `CLIENTS` — клиентская база, статистика визитов и flags VIP/Blacklist.
- `CLIENT_NOTES` — отдельная хронология комментариев о посетителе.
- `HISTORY` — аудит действий по броням.
- `SETTINGS` — стандартная смена 23:00→06:00 и cutoff операционного дня.

Бронь хранит номер стола независимо от схемы. При смене схемы клиент не пересаживается автоматически: если прежнего номера нет, администратор видит конфликт и решает его вручную.
